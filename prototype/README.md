# ElinkMemo 高保真原型（v0.1）

## 怎么打开
- 电脑 Chrome：http://127.0.0.1:4173/ （自动套 674×896 的 Leaf2 画布，画布外灰色）
- Leaf2 浏览器：http://192.168.0.31:4173/ （全屏铺满，无画布边框；手机/平板建议加书签）
- 设备诊断：http://192.168.0.31:4173/diag.html （把这组数字截图给 Lead）

服务如果停了，在项目根目录运行：
    python3 -m http.server 4173 --bind 0.0.0.0 --directory prototype
（Mac 防火墙若拦截，请在系统设置里允许 python 接收入站连接；Leaf2 需与 Mac 同网段）

## 交互清单
- 右滑一行 = 划掉 / 再右滑恢复（在浏览器里请从行中间开始划，屏幕边缘手势会被浏览器当成返回）
- 点击或左滑一行 = 编辑；底部输入条回车保存，Esc 或 × 取消
- 底部右「+」= 新增，回车连续添加并自动跳到末页；空行回车退出输入
- 底部左「⋯」= 设置（WebDAV 设置 / 立即同步 / 归档已完成 / 归档记录 / 关于）
- 翻页：上下滑；桌面可按键 PageUp / PageDown 或 ↑ / ↓
- 归档记录里点击条目 → 还原为未完成 / 永久删除 / 取消

## 演示与调试
- 数据存在 localStorage；URL 加 ?reset=1 可重置演示数据
- 同步为模拟：地址 / 用户名 / 密码任一为空 → 失败；否则成功；地址里含 fail 也会失败
- 这是设计契约，最终 APK 用 Kotlin + Compose 重写对齐；首次启动的提示框操作一次后永久消失
