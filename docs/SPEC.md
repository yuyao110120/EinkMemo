# EinkMemo · 规格说明书

状态：已与用户确认（2026-10-18）。本文件为冻结规格，编码阶段以本文件为准。

## 1. 目标
个人单用户墨水屏便签 / 待办。极简主页面、分页列表、完成划掉、手动 WebDAV 同步、针对墨水屏的零动画与分页显示。面向通用 Android 墨水屏设备。

## 2. 设备与交付
- 设备：通用 Android 墨水屏设备（minSdk 26；自适应分辨率，支持横竖屏）
- 最终形态：Kotlin + Jetpack Compose 原生 APK（compileSdk 34 / targetSdk 30 / minSdk 26，debug 自签）
- 流程：HTML 高保真原型 → 用户确认冻结 → Compose 实现 → APK 真机测试
- 保留系统状态栏（非沉浸式）；界面中英双语（跟随系统语言）；二级页顶部「← 返回」，系统返回同时可用
- App 名：EinkMemo；图标：1-bit 方案另行确认

## 3. 页面结构

### 主页面
- 无标题 / 日期 / 计数；列表从状态栏下开始；底部操作栏 44dp 高：左「⋯」设置、中页码、右「+」新增
- 每页行数按可用高度自适应（3–10 行，行高 ≥56dp；横竖屏自动重排）；超过则分页；翻页：上下滑 + 实体翻页键
- 页码仅在多页时显示（如 2/3）
- 行：每条前 46×46 像素小图 + 单行文本，文本超长省略；行间 1px 纯黑分隔线（Q22 = B）；正文随行高等比适配（原型取行高 40%，85px 行高 → 34px），并按本机字体度量做光学垂直居中；APK 阶段换算为 sp 真机校准
- 已完成：删除线 + 50% 灰（#808080），原地保留
- 首启一次性提示「右滑划掉 · 点击编辑 · 点小图换位 · 上下滑翻页」，任何操作后永久消失

### 二级页（整页切换、零动画，统一行高 64dp）
- 设置：WebDAV 设置 › / 立即同步（上次时间·结果）/ 归档已完成 (n)（执行归档）/ 归档记录 (m) › / 字体（系统 / 像素） / 帮助 › / 关于 ›
- WebDAV 设置：地址、用户名、密码、远端文件、测试连接、保存（全部 64dp 行高，标签左置、输入框右置；测试结果作为「测试连接」行内副文本）
- 归档记录：按归档日期倒序分组；点击行 → 操作条：还原为未完成 / 永久删除 / 取消
- 关于：版本、字体署名

## 4. 交互规范
- 右滑（≥36px 水平）切换完成 / 未完成；再滑一次即撤销
- 左滑或点击行 = 编辑；底部单行输入条，回车保存、Esc / × 取消
- 点条目前的像素小图 = 选中该条（整行反白，底栏提示「点另一条交换」）；再点任意一条交换两条位置；再点小图或返回键取消
- 新增：「+」→ 输入条；回车保存并保持输入状态；追加到列表末尾并自动跳到末页
- 无复选框、无删除手势、无撤销提示条、无反色闪烁、无跟手动画
- 上下滑（≥48px 垂直）= 翻页；桌面浏览器用 PageUp / PageDown 或 ↑ / ↓ 模拟实体键
- 空文本保存：新增时忽略；编辑时视为取消
- 归档：仅设置页手动触发，绝不自动
- 还原：归档条目回到主列表末尾、未完成状态

## 5. 视觉规范（1-bit）
- 色板：纯黑 #000 / 纯白 #fff；唯一灰 #808080 仅用于「已完成」文字
- 直角、1px 实线、无阴影 / 圆角 / 渐变 / 半透明 / 过渡 / 动画
- 字体：系统黑体（Noto Sans CJK 系）或内嵌像素字体（Fusion Pixel Font 12px proportional，SIL OFL 1.1），设置内切换；不加粗
- 每条列表项前固定 46×46 像素画小图（makebead SVG）：1-bit、关闭抗锯齿、按行高等比放大到整数倍并垂直居中；图标到屏幕、图标到文字的视觉间距一致（12dp）
- 底部操作栏 40dp；主页面按钮仅图标（约 40dp）
- 多分辨率与横竖屏：行数、行高、字号随可用空间等比适配，不出现遮挡
- 国际化：界面中英文案随系统语言切换（values / values-zh-rCN）

## 6. 数据模型
items[] 字段：id / text / done / createdAt / doneAt / archivedAt / updatedAt
- done 且未 archivedAt = 主页已划掉；archivedAt 非空 = 已归档
- 排序：按数组顺序（新增追加末尾）；还原条目移到末尾
- 本地持久化：每次操作立即写本地；无后台任务、无推送

## 7. 同步（WebDAV，手动）
- 远端单文件，默认 EinkMemo/notes.json；文件内容与本地同构（version + items）
- 流程：GET 远端 → 比对版本 / lastSync → If-Match 条件写 → 412 时重新 GET 合并重试
- 单设备简化：本地 / 远端单向变更自动判定方向；两边都变 → 极简二选一（保留本机 / 保留远端）
- 入口：设置页「立即同步」；启动不自动；成功零痕迹；失败在主页底部显示「同步失败 · 点此查看」（点击进设置）
- 凭据：Android Keystore（原型阶段 localStorage 演示）；明文 HTTP 仅允许用户配置的具体地址（network security config 白名单）
- 原型阶段：全部为界面与状态模拟，不发送真实网络请求

## 8. 墨水屏优化
- 零动画 / 零过渡 / 无涟漪；整页切换替代局部动效；分页替代滚动
- 操作只改局部；依赖系统整刷；v1 不引 Onyx 私有 SDK；刷新策略预留可插拔接口
- 已知限制：v1 无法 App 内强制整页刷新；真机残影不可接受再补 Onyx SDK（EpdController），不推翻 UI

## 9. 明确不做
勾选框 / 删除手势 / 长按 / 拖拽排序 / 多清单 / 标签 / 日期提醒 / 搜索 / 深色模式 / 自动或后台同步 / 账号体系 / 清空归档 / WebView 壳 / v1 接 Onyx SDK

- M1 原型：Chrome（674×896 画布）+ Leaf2 浏览器操作验收；覆盖主列表 / 新增 / 完成 / 分页 / 归档 / 设置 / 同步模拟
- 冻结范围：视觉规范 + 交互 + 页面清单；允许真机字体渲染导致的版式微调与刷新策略调整；新增功能另议
- M2 APK：JDK17 + cmdline-tools + Gradle 8.7 / AGP 8.5.2 构建；debug 自签；adb install 或 BooxDrop；用户真机测试
- 待真机校准：实际 viewport / DPR（诊断页）、实体翻页键 keycode、字体渲染、残影程度、EpdController 是否可用（若后续引入）
