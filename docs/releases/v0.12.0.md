## EinkMemo v0.12.0

### New

- **Language switch in Settings**: follow the system language, or choose English / 简体中文 manually. The choice persists and applies immediately.
- **Landscape doodle fix**: the pixel doodle before each note now scales continuously with the row height, so it no longer looks too small in landscape or on smaller screens.

### Also included

- 1-bit minimal list, swipe-to-cross, tap/swipe-left to edit, continuous adding
- Tap the doodle to select a row, then tap another row to swap positions
- Manual WebDAV sync with conflict choice; credentials encrypted via Android Keystore
- Archive, system and pixel fonts, responsive layout (3–10 rows), portrait and landscape

### Install

1. Download `EinkMemo-0.12.0-debug.apk` below.
2. Install it over EinkMemo 0.11.0 (same package and signing key, data preserved).

Debug-signed for sideloading. Source, docs and build instructions in the repository.
