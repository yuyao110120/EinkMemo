## ElinkMemo v0.7

墨水屏极简便签 / 待办。目标设备：文石 Boox Leaf2（7 英寸 / 300ppi / Android 11），Kotlin + Jetpack Compose 原生实现。

### 本版新增

- 内置像素字体 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)（12px proportional · zh_hans，SIL OFL 1.1）
- 设置 → 字体：系统字体 / 像素字体一键切换，选择持久化
- 像素字体覆盖主列表、二级页、输入框与关于页；行内光学居中按当前字体计算
- 关于页字体署名、帮助页字体切换说明

### 功能概览

- 单页极简：无标题栏、固定 10 条/页分页、纯黑白零动画
- 右滑划掉（删除线 + 灰），点击 / 左滑编辑，`+` 连续新增
- 已完成原地保留，设置页手动归档；归档记录可还原 / 永久删除
- 手动 WebDAV 同步（单文件 `notes.json`，内网 NAS），冲突二选一
- WebDAV 凭据 AES-256-GCM 加密存 Android Keystore，旧明文自动迁移
- 实体翻页键 / 音量键 / 方向键翻页；键盘弹出时列表等比缩放
- 40dp 底栏、简笔便签图标、帮助页、版本号自动同步

### 安装

1. 下载本页附件 `ElinkMemo-0.7-debug.apk`，拷到设备
2. 点击安装；首次需允许「安装未知应用」。可覆盖安装旧版（同签名），数据保留
3. 设置 → 字体，可切换系统字体 / 像素字体

debug 签名，可直接侧载。源码与文档见仓库 README。
