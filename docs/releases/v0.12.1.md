## EinkMemo v0.12.1

### Fixes

- **Landscape + keyboard**: the list now keeps its page row count and shrinks proportionally when the input bar opens, instead of just showing fewer, full-size rows.
- **Landscape Settings**: secondary pages (Settings, WebDAV, Language) are now scrollable, so all rows remain reachable on short screens.

### Included

- 1-bit minimal list, doodle-select-and-swap, manual WebDAV sync, archive, system/pixel fonts
- Language switch (follow system / English / 简体中文)
- Responsive 3–10 rows per page, portrait and landscape

### Install

1. Download `EinkMemo-0.12.1-debug.apk` below.
2. Install it over EinkMemo 0.12.0 (same package and signing key, data preserved).

Debug-signed for sideloading. Source, docs and build instructions in the repository.
