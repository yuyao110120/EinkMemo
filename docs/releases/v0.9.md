## ElinkMemo v0.9

墨水屏极简便签 / 待办。目标设备：文石 Boox Leaf2（7 英寸 / 300ppi / Android 11）。

### 本版新增

- 点条目前的像素小图 = 选中该条：整行反白，底栏提示「点另一条交换」
- 选中后再点任意一条 = 两条交换位置（顺序会保存并参与同步）
- 再点同一个小图、按返回键、翻页或进入设置 = 取消选中
- 选中期间暂停划掉 / 编辑 / 翻页手势，避免误触

### 功能概览

- 单页极简：无标题栏、固定 10 条/页分页、纯黑白零动画
- 右滑划掉（删除线 + 灰），点击 / 左滑编辑，`+` 连续新增
- 点小图选中、点另一条交换顺序；已完成原地保留，设置页手动归档
- 字体：系统字体 / 内嵌像素字体（Fusion Pixel Font）可切换
- 手动 WebDAV 同步（单文件 `notes.json`，内网 NAS），冲突二选一

### 安装

1. 下载本页附件 `ElinkMemo-0.9-debug.apk`，拷到设备
2. 点击安装；首次需允许「安装未知应用」。可覆盖安装旧版（同签名），数据保留

debug 签名，可直接侧载。源码与文档见仓库 README。
