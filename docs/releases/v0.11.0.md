## EinkMemo v0.11.0

First release under the EinkMemo name. UI is now available in **English and 简体中文**, and the layout adapts to different screens and orientations.

### New

- **Responsive layout**: rows per page adapt to screen size and orientation (3–10 rows, ≥56dp row height).
- **Landscape support**: rotation is enabled; pages reflow automatically.
- **Bilingual UI**: English by default, Simplified Chinese when the system language is Chinese.
- **Renamed to EinkMemo** across the app, docs and release assets (upgrade-compatible with previous ElinkMemo builds).

### Also included

- 1-bit minimal list with swipe-to-cross, tap/swipe-left to edit, continuous adding
- Pixel doodle before every note; tap it and then another row to swap positions
- Manual WebDAV sync with conflict choice; credentials encrypted via Android Keystore
- Archive for finished notes; system and pixel fonts

### Install

1. Download `EinkMemo-0.11.0-debug.apk` below.
2. Install it; allow installing unknown apps if asked. It can be installed over previous builds (same signing key, data preserved).

Debug-signed for sideloading. Source, docs and build instructions in the repository.
