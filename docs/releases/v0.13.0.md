## EinkMemo v0.13.0

### New

- **Three-zone drop on rows**: after tapping a doodle to select a note, tapping another row's area now works by thirds:
  - left third: insert the selected note **above** that row
  - middle third: **swap** the two rows
  - right third: insert the selected note **below** that row
- Tapping the selected row itself cancels the selection, as before.
- First-launch hint and Help now explain the three zones.

### Included

- 1-bit minimal list, manual WebDAV sync, archive, system/pixel fonts
- Language switch (follow system / English / 简体中文)
- Responsive 3–10 rows, portrait and landscape; keyboard scales the page; settings pages scroll

### Install

1. Download `EinkMemo-0.13.0-debug.apk` below.
2. Install it over EinkMemo 0.12.1 (same package and signing key, data preserved).

Debug-signed for sideloading. Source, docs and build instructions in the repository.
