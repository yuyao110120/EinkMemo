## ElinkMemo v0.6

墨水屏极简便签 / 待办。目标设备：文石 Boox Leaf2（7 英寸 / 300ppi / Android 11），Kotlin + Jetpack Compose 原生实现。

### 功能

- 单页极简：无标题栏、固定 10 条/页分页、纯黑白零动画
- 右滑划掉（删除线 + 灰），点击 / 左滑编辑，`+` 连续新增
- 已完成原地保留，设置页手动归档；归档记录可还原 / 永久删除
- 手动 WebDAV 同步（单文件 `notes.json`，内网 NAS），冲突二选一
- WebDAV 用户名/密码 AES-256-GCM 加密存 Android Keystore，旧明文自动迁移
- 实体翻页键 / 音量键 / 方向键翻页；键盘弹出时列表等比缩放
- 40dp 底栏、简笔便签图标、帮助页（操作 + 同步说明）、版本号自动同步
- 仓库内附 HTML 高保真原型（`prototype/`）与冻结规格（`docs/SPEC.md`）

### 安装

1. 下载本页附件 `ElinkMemo-0.6-debug.apk`，拷到设备
2. 点击安装；首次需允许「安装未知应用」
3. 打开后：设置 → WebDAV 设置，填 NAS 地址 / 账号 / 密码 → 测试连接 → 保存
4. 设置 → 立即同步

debug 签名，可直接侧载。源码与文档见仓库 README。
